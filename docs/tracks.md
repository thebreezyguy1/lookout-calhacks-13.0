# Prize-track checklist

Cal Hacks rules: teams of 1–4, all implementation during the event, submit on Devpost (team name, table number, 2–3 sentence pitch), 5-minute table judging, select every track on Devpost.

## Microsoft — Built for the Real World + Customer Impact Award
- [ ] Customer interview quotes (5+)
- [ ] Eval metrics: detection rate, false-alarm rate, time-to-detect
- [ ] "Path to production" slide (Nessie → Plaid, CRS sandbox → production, Azure deploy)
- [ ] Responsible design shown in product (consent, read-only, human approval)
- [ ] End-to-end live demo
- [ ] Ask at booth: does Azure usage earn points?

## Hyphenate — Autonomous Systems for Finance
- [ ] Get the CalHacks_Hyphenate_Track doc (booth / Slack)
- [ ] Demo video that opens with "the moment"
- [ ] Live demo; scenario injector judges can drive
- [ ] One line on the seats it fills
- [ ] What's real vs. simulated, and how we know it works

## CRS — Financial Intelligence Challenge
- [ ] Sandbox access (invite email → portal + Postman collection)
- [ ] Test identities only
- [ ] CRS central to the product; works live against the sandbox
- [ ] Targets: Best Financial AI Agent, Best Identity / Fraud Innovation, Best Overall

## Capital One — Best Use of Nessie
- [ ] API key (GitHub sign-up at api.nessieisreal.com)
- [ ] Judged on completeness, creativity, complexity

## Anthropic
- [ ] Named community: adult children of aging parents
- [ ] Real problem, lived or heard firsthand
- [ ] One thing done well, usable Monday
- [ ] Claude does something that matters; we know where it could go wrong
